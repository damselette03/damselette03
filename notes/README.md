# Chapter 2 詳細講解講義

依謝德宗《總體經濟學》Chapter 2「國民所得的衡量」投影片整理的逐頁詳細說明 PDF。

## 檔案

- `Chapter2_國民所得的衡量_詳細講解講義.pdf`：最終講義（含封面共 26 頁；其後每頁對應原 PPT 第 1–25 頁）
- `chapter2_pages.json`：各頁文字內容資料
- `generate_chapter2_notes.py`：由 JSON 產生 PDF 的腳本

## 重新產生

```bash
python3 notes/generate_chapter2_notes.py
```

需要系統字型：`/usr/share/fonts/truetype/wqy/wqy-microhei.ttc`，以及 Python 套件 `reportlab`。
