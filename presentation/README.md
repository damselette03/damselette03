16:9、7 張。用 PowerPoint / Google 簡報 / WPS 開啟皆可。

## 這份可以怎麼改

所有文字、色塊、照片都是**獨立物件**，沒有合併、沒有鎖住。

- **改字：** 直接點文字框，像一般投影片一樣打字。
- **移動／刪除：** 點選後拖曳或按 Delete。照片、圖示、白卡片、左邊深藍直條都可以單獨刪。
- **換照片：** 點照片 → 圖片格式 → 更改圖片。
- **講稿：** 檢視 → 備忘稿。每張都有英文要講的句子，以及中文時間提示。
- **選取窗格：** 常用 → 選取 → 選取窗格。照片與卡片已命名（例如 `Photo_Ohtani_portrait`、`Quote_added`）。

若整份重做：在本資料夾執行 `python3 build_pptx.py`。
